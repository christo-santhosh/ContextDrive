\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Agriculture is affected by changing weather, soil conditions, and inefficient use of water and fertilizers. This project, \textbf{Farming Intelligence AI}, presents a cloud-based smart farming platform that supports data-driven agricultural decision-making.

The system uses an IoT-based 7-in-1 soil sensor connected to an ESP32 to collect soil parameters such as N, P, K, pH, moisture, temperature, and electrical conductivity, along with weather information. A machine learning model recommends the top three to five suitable crops and provides fertilizer and irrigation guidance. Market intelligence and price forecasting support profitability-based crop selection.

The system integrates Explainable AI techniques such as SHAP and LIME to improve the transparency of crop recommendations. A Retrieval-Augmented Generation (RAG) assistant provides agricultural guidance using a curated knowledge base. The platform also supports multilingual interaction, real-time soil monitoring, weather-based insights, and a responsive interface for desktop and mobile devices.

By combining IoT, machine learning, XAI, market intelligence, and RAG technologies, the platform provides farmers with an integrated solution for crop selection, resource management, agricultural guidance, and informed decision-making.
